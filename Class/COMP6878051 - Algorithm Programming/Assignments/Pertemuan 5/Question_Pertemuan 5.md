## 1. IPK Grading
Create a program to input a student's IPK (cumulative performance index) and display the corresponding grading.

| Range       | Grade       |
|-------------|-------------|
| 3.5 – 4.0   | Cumlaude    |
| 3.0 – 3.4   | Outstanding |
| 2.5 – 2.9   | Very Good   |
| 2.0 – 2.4   | Good        |
| < 2.0       | Poor        |
**Requirement:** Use IF or IF-ELSE

## 2. Student Score Grading
Create a C program to input a student's score (0–100) and display the corresponding grade.

| Range     | Grade |
|-----------|-------|
| 85 – 100  | A     |
| 75 – 84   | B     |
| 65 – 74   | C     |
| 50 – 64   | D     |
| < 50      | F     |
**Requirement:** Use IF or IF-ELSE

## 3. Temperature Category
Create a C program to input a temperature in degrees Celsius and display its category.

| Range               | Category  |
|---------------------|-----------|
| Below 20°C          | Cold      |
| 20°C to below 30°C  | Normal    |
| 30°C to below 35°C  | Hot       |
| 35°C or above       | Very Hot  |
**Requirement:** Use IF or IF-ELSE

## 4. Age Category
Create a C program to determine the age category of a person.

| Range   | Category   |
|---------|------------|
| 0 – 5   | Toddler    |
| 6 – 12  | Children   |
| 13 – 18 | Teenagers  |
| 19 – 59 | Adult      |
| ≥ 60    | Elderly    |
**Requirement:** Use IF or IF-ELSE
